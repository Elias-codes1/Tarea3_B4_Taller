# Tarea3_B4_Taller

Aplicación desarrollada en Angular (standalone components) que simula el carrito de compras de una tienda de periféricos de computadora. Permite visualizar un catálogo de productos, agregarlos a un carrito, modificar la cantidad de cada uno y eliminarlos, mientras la interfaz calcula y muestra en tiempo real los subtotales y el total.
